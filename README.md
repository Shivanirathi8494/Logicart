# Logicarts Logistics Management System (LMS)

## Overview

Logicarts LMS is a modern logistics management platform consisting of:

- Corporate Website
- Shipment Tracking
- Customer Portal
- Operations Dashboard
- Docket Management
- Inscan / Outscan
- Manifestation
- Delivery Challan
- Reports

---

## Technology Stack

### Frontend

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS v4

### Backend (Phase 2)

- NestJS
- PostgreSQL
- Prisma ORM
