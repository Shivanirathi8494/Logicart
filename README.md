# Logicarts Logistics Management System (LMS)

A modern logistics and cargo management platform designed to simplify shipment management, cargo tracking, and logistics operations across India.

---

## Project Overview

Logicarts LMS consists of two major parts:

### Public Website
- Home
- Services
- Shipment Tracking
- About Us
- Career
- Contact Us

### Logistics Management System (Upcoming)
- User Authentication
- Operations Dashboard
- Create & Manage Dockets
- Shipment Tracking
- Manifest Management
- Barcode & QR Code Support
- Inscan / Outscan
- Reports & Analytics
- Customer Portal
- Admin Portal

---

## Technology Stack

### Frontend
- Next.js (App Router)
- React
- TypeScript
- Tailwind CSS
- shadcn/ui

### Planned Backend
- Node.js
- Express.js / NestJS
- PostgreSQL
- Redis
- REST APIs
