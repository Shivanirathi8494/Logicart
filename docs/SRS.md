
# Air Cargo Functional Requirements

## FR-11 Create Docket

The system shall allow operators to create an air cargo shipment.

## FR-12 Tracking Number

The system shall generate a Tracking Number using:

- Origin Airport
- Destination Airport
- Booking Date
- Daily Sequence Number

Example:

BLR-DEL-260803-000001

## FR-13 Shipment Details

The system shall support multiple packages.

Each package shall include:

- Length
- Width
- Height

The system shall automatically calculate:

- Volumetric Weight
- Chargeable Weight

## FR-14 Payment

The system shall calculate:

- Freight
- GST
- Total

The system shall support UPI QR Payment.

## FR-15 Air Waybill

The system shall generate a printable Air Waybill.
